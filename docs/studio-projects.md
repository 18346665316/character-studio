# Studio 素材项目

项目用于组织素材需求、共同风格和当前成果。用户在项目中查看图片及信息，进入工作台编辑，需要时进入验证工具；没有“采用 → 审核 → 交付”的必经流程。

整体制作方法见 [Studio 定位与素材制作总流程](production-workflow.md)：先明确用途、拆解套件和建立共同基准，以代表性组合检查关键素材，再扩充内容并接入引擎。下文描述当前软件操作，不表示界面已实现独立的阶段管理。

## 当前操作

1. 建立项目，填写共同风格、视角和尺寸等制作条件。
2. 加入素材需求，直接生成或进入对应工作台制作；也可从素材库选择已有素材。
3. 生成的有效结果直接成为该项的当前素材，无需另点采用。再次生成失败或尚未完成时继续显示已有素材，错误在详情中反馈。
4. 点击图片查看大图、尺寸和需求；通过“编辑素材”进入当前成果的工作台。
5. 需要验证时打开“验证工具”：组合预览检查比例、配色和搭配；模块场景检查拼接、碰撞和动作等实际接入效果。验证不作为制作或下载的前置条件。

项目清单不展示“已采用”“待挑选”“已采用 · 再生成失败”等流程状态，不展示生产历史列表。生成中的按钮提供必要的进度反馈。项目不再提供整套交付、发布版本和历史交付页面。各素材工作台保留实际需要的文件下载。

## 当前素材的规则

- 新生成的有效结果按关联任务解析；失败或运行中的任务不覆盖上一次有效成果。建筑已通过现有文件检查的图片可直接显示。
- 手动从素材库选择时保存素材引用，不复制图片和 ZIP、不创建交付记录。较晚的手动选择优先于此前的生产结果；之后新生成的有效结果继续更新当前素材。
- 读取既有项目时兼容原有 selected 字段，但项目展示和组合预览读取原素材的当前内容，不使用旧快照作为当前图片。
- 从项目进入当前物件的工作台，保存设置产生新的素材编号时，自动更新该项引用，不再要求手动采用。
- 人物图片取当前动作集首帧；人物尚无有效动作集时仍需进入人物工作台准备动作。
- 组合的位置、显示比例和备注只用于预览，不修改原素材。未完成的需求不阻止已有素材的组合预览。

模块验证场景目前仍保留自己的素材引用与导出机制，本轮没有把它迁移为实时跟随全部素材修改，也没有改写旧项目或删除既有交付文件。已删除项目交付包创建逻辑及发布接口；旧快照与已有交付文件仅保留读取兼容，项目界面不再使用。

## 失败物件原图的背景修正

生产任务保留原图时，可在物件任务记录中打开“修正背景（不生图）”。在原图内部的纯色背景空洞点选，例如竹筐提手内侧；支持撤销和清空，最多64点。预览会显示棋盘、深色和浅色背景，对照检查孔洞、细边与主体。标记变化后须重新预览，才能另存为素材。

另存复用原图与生成回执，保存背景标记，原失败记录不变，并提供修正版本链接；再次提交同一预览复用同一版本。新版本可正常下载、编辑尺寸/锚点/碰撞或从素材库选入项目。此操作不自动替换项目当前素材。

点选只扩展接近背景色的连通区域，不识别结构、不修复文字或投影，也不放宽剩余颜色清理的安全阈值。点到主体会被拒绝，复杂原图仍可能失败。墙体和院落任务继续使用对应流程。

## 批量导入清单

素材清单内点击“批量导入清单”，粘贴或选择 JSON 文件，预览后导入。
格式为 `{"items":[{"kind":"prop","title":"木箱","description":"单个关闭的农用木箱"}]}`，也接受直接的数组。
类型使用界面列出的标识；名称最多 60 字，描述最多 2000 字，一次 1–200 项，项目上限 200 项。
同类型同名条目跳过，不覆盖已有需求或共同风格；导入不启动生成。

## 删除

项目卡片支持删除项目，共用素材保留。素材详情支持删除该项需求，素材库成果保留。素材库、人物库和验证场景保留各自的删除入口。
删除素材前检查当前项目引用及验证场景等依赖；存在引用时给出具体位置。
