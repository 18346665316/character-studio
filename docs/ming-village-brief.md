# 明代村落制作说明与代表性组合

更新：2026-11-04。依据 [制作总流程](production-workflow.md) 记录使用目标与代表性组合。现已完成农家操作小样和现有产出审查，逐项处理见 [素材清单](ming-village-asset-inventory.md)，实际显示效果见 [产出审查](production-output-review-2026-11-04.md)。地域、尺度与镜头仍是工作假设，允许在小样中修订。

## 使用目标

最终目标仍是内容丰富、面积足够大的明代村落场景套件，以及能验证其使用效果的 Godot Demo；素材从本次项目制作，不引用旧宋村或其他旧场景素材。当前明代项目内部已经生成的素材可以继续使用。

工作假设为明代江南平原普通农耕村落，表现民居、田地、村路、公共用水、生活生产与小型贸易。参考和描述由制作者准备、判断；“江南”沿用本项目已有方向，不代表已完成具体县域和年代考证。

使用方式是地面行走的 2D 等距游戏：固定正交相机，地面两轴斜率 ±0.5，建筑不进入室内。玩家需要看清道路、绕过建筑和器物，能从物件前后走过并观察遮挡。第一轮组合以白天的同一光照、固定镜头和普通住宅周边空间为对象。

## 首个组合：村路旁的一户农家

选择这个空间，是因为它能同时暴露地表衔接、人物与房屋比例、大小器物、植物、占地和排序问题，所需候选也已存在。小样先控制在一个主要镜头内，约 9×9 个 128×64 地格；实际范围随构图调整。

内容为一座茅舍、一段经过门前的夯土村路、一棵柳树、两小块菜畦，以及水缸、鸡笼、木推车各一件。保留能够绕屋和经过菜畦的路径。房前留工作空间，器物贴近其使用位置，不按等距点阵平均摆放。石井等公共设施留到下一组公共空间，桥和院墙留给各自的专项组合。

小样不依靠新增任务玩法证明效果。先查看目标镜头，再实际走过前路、侧路及屋后；发现素材不适用时回到对应工作台调整或换候选。

## 尺度与镜头

Studio 已采用“标准人高 = 1”。编辑器、模块场景参照和新导出测试标记一致；人物制作分辨率表示清晰度，不表示场景中的实际身高。换算规则见 [模块场景尺寸说明](module-scene-mvp.md#尺寸交互)。

当前小样使用 128×64 地格、1100×760 视口、相机 1 倍；此镜头下参照高 34 像素。下表是实际走查输入值，不是考证尺寸或正式规格，也不意味着都已通过。正式人物接入后还需检查轮廓与动作。

| 内容 | 小样主体高（标准人高） | 查看重点 |
| --- | --- | --- |
| 人物参照 | 1 | 目前是尺度标记，不能代替正式人物 |
| 茅舍 | 5.2 | 门与人物比例；若整体缩放无法兼顾内部结构，应换候选 |
| 柳树 | 6 | 树干落地、树冠与房屋搭配 |
| 水缸 | 0.6 | 实际约高20像素；容器可辨，但细节不足以直接支持交互识别 |
| 鸡笼 | 0.5 | 实际约高17像素；当前难以独立识别为鸡笼 |
| 木推车 | 1.1 | 轮、车斗和车把可辨；占地和人物搭配仍需检查 |
| 菜畦 | 1.4 | 这是投影图像主体高度，包含地块纵深，不代表作物真实长到1.4人高 |

这些尺寸用于第一次摆放后目视调整，不代表真实尺寸测量。房门等内部结构若与主体比例冲突，不能靠整体缩放单独修正。碰撞应依据画面中的地面接触与占地标注，不能把完整建筑画面包围盒用作碰撞。

## 一次完整制作怎样进行

1. 在现有工作台查看上述原图和深浅背景预览，确认哪些适合作为第一候选；记录看见的问题。
2. 新建独立的小型模块场景，保留现有大 Demo。采用本项目候选，使用公共素材编辑器设置实际尺寸、脚底锚点和占地。修改创建派生版本，保留来源。
3. 放置房屋、道路与人物尺度参照，先解决门和人物比例；再加入器物、植被与菜畦，按目标镜头调整位置和大小。
4. 在 Studio 看组合和通行空间，导出 Godot；实际走过屋前、屋侧、屋后以及器物两边，观察排序和碰撞。
5. 对实际问题选择修尺寸、锚点、碰撞、布局、提示词或换候选。涉及新图片时只制作这个组合确实缺少或不合用的素材。
6. 记录输入、操作、输出、问题与处理结果。对软件改进的建议要有具体操作证据；已有能力可完成的，先用现有能力。

已走通人高输入、过渡选块、保存和导出，详见 [改进记录](studio-polish-log.md)。当前优先处理产出是否满足用途：先查原图、处理边缘和目标镜头辨识度，不继续优先扩展摆放操作。

## 何时扩充

首个组合应能在固定镜头中读成一处可使用的农家空间：门、人和物件的比例相容，草土过渡不抢画面，主要路径连续，建筑和器物在预期位置阻挡，角色前后经过时没有影响阅读的错误遮挡。未达到时继续修这个组合。

组合成立后分三批推进：先做第二户和公共水井空间，检查同类变化与共享尺度；再做耕作、晒粮和小型交易空间，补充内容；最后做水岸、桥、院墙等需要专项验证的元素，并逐步连接成较大村落。每批都沿用已成立的基准，并保留实际发现的问题。

大场景最终完成情况以不同空间的丰富度、素材可重新组合性、实际画面和路径使用情况共同判断。地格数量只说明面积。
