# 四合院院墙：重新制作

新素材项目 `20261103-213712-24c6e327`，名称“四合院 · 院墙重建”。本轮先制作一个固定尺寸的闭合院墙，不含房屋、院门、地面及碰撞，不沿用此前独立直墙与转角。

`pipeline/courtyard_ring.py` 生成四边线框，使用现有 Studio 图片服务一体绘制院墙。项目物件通过 `wall_template` 的 `axis=ring` 绑定此配方，项目页“生成”与工作台共用 `static_props.prepare/execute`。生成失败时原有项目素材保留；继续任务复用已下载原图。

程序检查院心透明且不与外界连通，内空像素不少于 12000，再按固定投影分区切出四角、四边。每件使用 768×768 画布和统一锚点 `(384,400)`，只选择来源像素并作整数平移。额外保留完整院墙素材作为项目当前预览，引用八件切片。切片必须逐像素重建完整来源且无重叠；不是可任意互换或独立重复的模块套件，也没有自动验收造型、标准墙高、角色尺度和物理遮挡。

真实任务 `20261103-213712-7e005fa2` 使用一张 AI 来源图。处理阶段修正了 Pillow 只读图像的填充检查及切片画布空间，均复用这张来源，没有再次生图。最终闭合检查通过，透明院心 35748px，重建误差为零。完整素材 `20261103-213832-891a6065`；其 `assembly_parts` 引用八件切片。

验证场景 `7ace5b4451c78635` 由 `create_validation_scene(root, job_folder)` 使用固定原坐标组装，八件素材、八个实例。再次调用复用场景，不覆盖用户编辑。画布统一缩放合成可避免切片透明采样缝。浏览器实际加载无页面错误，项目“重新生成”按钮可用。
