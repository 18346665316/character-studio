# 统一风格与提示词

## 数据放在哪里

Studio 项目 `baseline` 是当前共同制作条件的来源。不要在 skill 中固化题材、色板或模型；不要随意覆盖已有基准。现有字段：

| 字段 | 含义 / 约束 |
| --- | --- |
| `view` | `isometric_2_1`、`orthographic_three_quarter`、`top_down` |
| `cell_px` | 64 或 128；制作地格规格，不是人物身高 |
| `character_height_px` | 16–512整数；人物制作分辨率，不改变人高参照 |
| `style` | 题材、绘画方式、形状语言等共同描述 |
| `palette` | 配色与材质范围 |
| `lighting` | 光源方向与明暗强度 |
| `camera_rules` | 相机与空间绘图约定 |
| `orientation_rules` | 朝向规则；建筑专有规则用于普通物件时检查是否冲突 |

文本字段各最多2000字；继承后的物件描述总计仍受2000字限制。字段不是自动视觉验证器。若修改共同条件，先读项目 revision，保存后读取新 `baseline_revision`；已有图片不会自动重画。

图像参考通过各工作台输入保存，当前普通项目 baseline 没有全局 `reference_image` 字段。AI 必须显式上传到此次任务；可跨小批次沿用同一张经过查看的参考，记录路径/ID与SHA-256。参考只约束画风时明确写出“不复制主体、构图和背景”。不要把PNG转成文字描述当作已上传图像。

## 单件提示词组织

把以下信息整理为物件描述；普通物件后端会自动补充视角、纯品红、单主体、无文字和留白规则，避免再写冲突的透明背景/白底等要求。

- **用途**：放在什么空间，是普通陈设还是必须辨识的交互对象。
- **结构**：可观察的部件、数量与连接；“一个矮木凳：厚座面、四条粗短腿、无靠背”比仅写“明代家具”可检验。
- **显示**：期望人高比例、最终镜头下约多大像素范围，要求保留哪些轮廓；提示词不替代实际缩小查看。
- **画风**：继承项目基准，点出大色块、材质、细节密度与参考的作用。
- **禁项**：针对本次风险列出额外主体、底座/地面、投影、文字和结构误解；禁止词不保证模型遵守。

历史结构未确认时，把候选称作题材陈设，不作历史认证。需要准确复原时先找针对该器物的可靠资料；保持结构参考与画风参考的职责区别。

### 填写示例（只是示例，不是内置 preset）

用途：农家门前的普通矮木凳陈设。只画一件厚长方形座面、四条短粗木腿的完整木凳，没有靠背、扶手或雕花。旧木褐，大明暗块、少量宽板接缝；最终在约二十多像素宽显示时仍能分辨凳面和腿。沿用项目的手绘方式、视角和左上柔光。上传图只参考笔触与配色，不复制其中器物。腿间为空背景，不带人物、地面、文字、尺寸标注或投影。

## 比例与镜头一起看

标准人高为1。当前实现兼容换算 `1人高 = 34场景单位`；镜头1倍时参照高34渲染像素，2倍为68。人物动作包不会自动归一化。场景摆放比例需要根据正式人物与目标镜头检查。

`world_scale = 目标主体高(人高) × 34 ÷ Alpha包围盒高(px)`，主体宽同理。宽高等比联动，原图不重采样。Alpha非零像素含阴影和碎屑；先看包围盒是否可靠。

2D等距地块的图像高度包含地面纵深，不能当作真实竖直高度。源图256画布也不表示所有物件同大。不要为看清细节任意放大单件器物；先比较相同物体比例下的镜头倍率。不要仅靠提高源图分辨率承诺小尺寸辨识度。
